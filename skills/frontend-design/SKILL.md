# Frontend Design Skill

## Objetivo
Criar interfaces web modernas, bonitas e funcionais com alto padrão de design.

## Regras
- Sempre usar HTML, CSS e JS em arquivo único, salvo se pedido diferente
- Priorizar design limpo, moderno e responsivo
- Usar variáveis CSS para cores e tipografia
- Evitar estilos genéricos — cada projeto deve ter identidade visual própria
- Preferir flexbox e grid para layouts
- Animações suaves onde fizer sentido

## Stack padrão
- HTML5 semântico
- CSS moderno (variáveis, grid, flexbox)
- JavaScript vanilla ou React se solicitado
- Tailwind se o projeto já usar

## Entregáveis
- Código completo e funcional
- Comentários explica
